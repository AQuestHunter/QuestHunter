🧩 2. STRUCTUUR VAN EEN VRAAG


Elke vraag bevat:


📍 Titel


Kort, dreigend


📖 Context


    2–5 lijnen

    ondersteunt de puzzel


🧩 Challenge


    visueel afgescheiden (codeblok / symbolen / afbeelding)

🎯 Input

🔧 3. VRAAG DESIGN REGELS


    Vraag = probleem, geen directe vraagstelling
    Bevat:
        mechaniek
        context
        ruis (max 30%)
    Dwingt interpretatie, geen herkenning
    Gokken mag niet werken
    Minstens 1–3 stappen afhankelijk van moeilijkheid

🧠 MECHANIEK SYSTEEM — COMPLETE SAMENVATTING

🎯 FUNDAMENT

Elke quest = combinatie van mechanics, geen losse puzzel.

Minimaal per quest:

    2 categorieën combineren
    1 moment van twijfel
    1 “aha” moment

Anders is het gewoon huiswerk met cosplay.


🔐 1. ENCODING (toegangspoort)

Doel: info verbergen, niet oplossen.

Voorbeelden:

    Caesar, Vigenère, Morse, Binary, Base64
    Atbash, Playfair, Rail Fence, Columnar
    Hex, ASCII, Unicode

Gebruik:

    Layered (meerdere op elkaar)
    Verstopte encoding (bv. in afbeelding)
    Foute sleutel → plausibel fout antwoord

👉 Encoding = slot, niet de puzzel zelf.


🧩 2. LOGICA (structuur)

Doel: denkwerk forceren.

Voorbeelden:

    Reeksen, patronen, matrix
    Deductie (wie liegt)
    Constraint puzzles

Gebruik:

    Regels veranderen
    Meerdere mogelijke oplossingen
    Context bepaalt juiste

👉 Logica = twijfel creëren.


🕵️ 3. CONTEXT-BASED (verhaal als mechanic)

Doel: info verstoppen in narratief.

Voorbeelden:

    Datums = shifts
    Namen = codes
    Dialogen = hints

Gebruik:

    Onbetrouwbare info
    Belangrijke details lijken irrelevant
    Keuzes beïnvloeden interpretatie

👉 Verhaal = actief onderdeel, geen decor.


🌐 4. OSINT-FEEL (realiteit simuleren)

Doel: immersion en “echtheid”.

Voorbeelden:

    Fake websites / profielen
    Metadata (EXIF, timestamps)
    Verborgen info in bestanden

Gebruik:

    Tegenstrijdige bronnen
    Incomplete info
    Cross-referencing nodig

👉 Spel voelt groter dan zichzelf.


🎭 5. MISLEIDING (essentieel)

Doel: spelers laten falen… geloofwaardig.

Voorbeelden:

    Red herrings
    Fake oplossingen
    Dubbele betekenissen

👉 Zonder dit = te makkelijk.


🔗 6. MULTI-LAYER

Doel: complexiteit opbouwen.

Voorbeelden:

    Output A → input B
    Encoding + logica + context samen
    Eén fout → alles fout

👉 Hier ontstaat echte moeilijkheid.


🧠 7. PSYCHOLOGISCH

Doel: emotie + twijfel.

Voorbeelden:

    Schuldgevoel bij keuzes
    Twijfel over juiste antwoord
    Informatie achterhouden

👉 Speler vecht tegen zichzelf.


🧱 8. VISUEEL / FYSIEK

Doel: andere denkkanalen activeren.

Voorbeelden:

    Afbeeldingen / blauwdrukken
    Symbolen / posities
    Kaarten

👉 Perfect voor variatie.


⏳ 9. TIJD / VOLGORDE

Doel: druk en impact.

Voorbeelden:

    Volgorde bepaalt uitkomst
    Te snel = penalty
    Gefaseerde info

👉 Stress = fouten.


🧪 10. META / INTERFACE

Doel: verwachtingen breken.

Voorbeelden:

    UI is deel van puzzel
    Hidden clicks / scroll
    “Foute” acties zijn juist

👉 Spelers vertrouwen niets meer.


⸻


📎 IMPLEMENTATIE (ENGINE — quest-hunter-web)


    Het product gebruikt XP als vaste punten op je profiel, met dezelfde bedoeling als de percentages hierboven:

    Hintlagen: tier 1 ×0.95, tier 2 ×0.90, tier 3 ×0.80 (cumulatief op het basis-XP van de stap).

    Foute pogingen op dezelfde stap: elk ×0.98 extra op het toe te kennen XP (stacking).

    Clean solve: +5% als er geen hints zijn gebruikt én geen foute pogingen op die stap.

    Finale-paden: OBSERVE ×0.94, INFLUENCE ×1.00, CONTROL ×1.06 op basis-xpFinale (default 75).

    Verborgen tellers: CONTROL / OBSERVE / INFLUENCE worden per gekozen finale opgeslagen in progress.state.hiddenAxes (voor latere branching).

    Zie quest-hunter-web/docs/AUTHORING_CHECKLIST.md voor auteurs-checklist en QA.


🗂️ 11. DATA CORRUPTIE

Doel: chaos als puzzel.

Voorbeelden:

    Kapotte tekst
    Overlapping data
    Missing info

👉 Lijkt random, is het niet.


🔁 12. ITERATIE / FALEN

Doel: leren via fouten.

Voorbeelden:

    Foute antwoorden geven hints
    Meerdere pogingen nodig
    XP-verlies (jouw systeem)

👉 Falen wordt mechanic.


🧍‍♂️ 13. ROLLEN / IDENTITEIT

Doel: keuzes impact geven.

Voorbeelden:

    Verschillende info per rol
    Andere oplossingen per pad

👉 Replay value + diepgang.


🧩 14. INCOMPLETE INFO

Doel: onzekerheid.

Voorbeelden:

    Te weinig data
    Interpretatie nodig
    Meerdere plausibele antwoorden

👉 Zekerheid wegnemen.


🔐 15. RESOURCE MANAGEMENT

Doel: spanning verhogen.

Voorbeelden:

    Beperkte pogingen
    Hints kosten XP
    Risico vs zekerheid

👉 Beslissingen worden zwaar.


🧠 16. PATTERN DISRUPTION

Doel: vertrouwen breken.

Voorbeelden:

    Regel verandert plots
    Bekend patroon faalt

👉 Spelers worden paranoïde.


🔗 17. CROSS-QUEST LINKS

Doel: één geheel maken.

Voorbeelden:

    Oude info opnieuw nodig
    Verbinding tussen quests

👉 Geen losse levels meer.


🎧 18. MULTI-SENSORY

Doel: onverwachte input.

Voorbeelden:

    Audio → code
    Kleur → cijfers
    Ritme → morse

👉 Andere hersengebieden activeren.


🧠 19. COGNITIVE BIAS

Doel: speler manipuleren.

Voorbeelden:

    Voor de hand liggend = fout
    Framing stuurt keuzes

👉 Brein tegen zichzelf gebruiken.


🧪 20. FALSE MASTERY

Doel: overconfidence straffen.

Voorbeelden:

    Lijkt hetzelfde → is anders
    Speler denkt het te snappen

👉 Valstrik voor slimme mensen.

    Geen interpretatie
    Case consistent (bij voorkeur lowercase) maar niet hoofdletter gevoelig
    Geen gokken mogelijk
    Antwoord voelt “verdiend”
